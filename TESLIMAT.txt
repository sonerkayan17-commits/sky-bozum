SKY BOZUM V2 - KURULUM

1. Mevcut sky-bozum klasörünüzün yedeğini alın.
2. Bu ZIP dosyasını masaüstüne çıkarın.
3. Çıkan sky-bozum-v2 klasörünü VS Code ile açın.
4. Terminalde sırayla çalıştırın:

npm install
npm run dev

5. Tarayıcıda açın:
http://localhost:3000

ÜRETİM KONTROLÜ
