# V38.2 İş Ortaklığı Entegrasyonu

- `/is-ortakligi` sayfası V38.1 tasarım sistemiyle entegre edildi.
- Navbar masaüstü ve mobil menüsüne İş Ortaklığı bağlantısı eklendi.
- Footer Kurumsal grubuna bağlantı eklendi.
- Merkezi statik rota listesi ve sitemap kaydı eklendi.
- Site içi arama indeksine İş Ortaklığı sayfası eklendi.
- Başvuru formu Firebase yapılandırması aktif olduğunda `partnershipApplications` koleksiyonuna `pending` durumuyla kayıt oluşturur.
- Firebase aktif değilse sahte başarı gösterilmez; kullanıcı resmi iletişim kanallarına yönlendirilir.
- Global CSS dosyasına müdahale edilmedi. Modül mevcut tema tokenları ve Tailwind sınıflarıyla çalışır.

- Entegrasyona dokunan dosyalarda ESLint: başarılı.
- Tüm proje TypeScript (`tsc --noEmit`): başarılı.
- İç bağlantı denetimi: 175 bağlantı, 0 şüpheli bağlantı.
